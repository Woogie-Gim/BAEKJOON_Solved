# PART 1. 완전탐색

## 1-1. 먼저 할 일 — 경우의 수 계산

완전탐색은 **되는지 안 되는지 먼저 계산**하고 들어간다.

> **기준: 1초에 약 1억 번 연산**

| 제한 조건 | 가능한 접근 |
|---|---|
| N ≤ 10~20 | 완전탐색 / 백트래킹 (지수 시간 OK) |
| N ≤ 100 | O(N³) 까지 |
| N ≤ 1,000 | O(N²) |
| N ≤ 100,000 | O(N log N) |
| N ≤ 1,000,000 | O(N) |

**N이 작으면(10~20) 완전탐색 신호.** 문제 제한 조건을 먼저 보는 습관을 들일 것.

## 1-2. 완전탐색 4가지 형태

| 형태 | 구현 | 경우의 수 |
|---|---|---|
| 모든 부분집합 | 비트마스크 or 재귀 | 2^N |
| 모든 순열 | `next_permutation` or 재귀 | N! |
| 모든 조합 | 재귀 (start 인자) | C(N, K) |
| 중복 허용 선택 | 재귀 | M^N |

## 1-3. 비트마스크 — 부분집합 완전탐색

N개 원소 중 임의 개수를 고르는 모든 경우.

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    int n = 4;
    vector<int> arr(n);
    for (int i = 0; i < n; i++)
    {
        arr[i] = i + 1;
    }

    // 0 ~ 2^n - 1 까지가 모든 부분집합
    for (int mask = 0; mask < (1 << n); mask++)
    {
        cout << "{ ";
        for (int i = 0; i < n; i++)
        {
            // i번째 비트가 켜져 있으면 선택됨
            if (mask & (1 << i))
            {
                cout << arr[i] << " ";
            }
        }
        cout << "}\n";
    }

    return 0;
}
```

### 비트 연산 정리

| 연산 | 의미 |
|---|---|
| `1 << i` | i번째 비트만 켠 값 |
| `mask & (1 << i)` | i번째 비트가 켜져 있는가 |
| `mask \| (1 << i)` | i번째 비트 켜기 |
| `mask & ~(1 << i)` | i번째 비트 끄기 |
| `mask ^ (1 << i)` | i번째 비트 반전 |
| `1 << n` | 2^n |

**N ≤ 20 정도까지만.** 2^20 = 약 100만으로 아슬아슬.

## 1-4. `next_permutation` — 순열 완전탐색

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    vector<int> v;
    v.push_back(1);
    v.push_back(2);
    v.push_back(3);

    sort(v.begin(), v.end());   // 반드시 정렬 후 시작

    do
    {
        for (int i = 0; i < (int)v.size(); i++)
        {
            cout << v[i] << " ";
        }
        cout << "\n";
    } while (next_permutation(v.begin(), v.end()));

    return 0;
}
```

**주의**
- 정렬 안 하면 일부 순열 누락
- `while`이 아니라 `do-while` (첫 순열도 처리해야 함)
- 가지치기 불가 → 필요하면 재귀로

# PART 2. 백트래킹

## 2-1. 왜 재귀인가

자리 수가 고정이면 for문으로 가능.

```cpp
// 2자리 3진수
for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 3; j++)
    {
        cout << i << " " << j << "\n";
    }
}
```

**N자리라면 for문 N개가 필요한데, N이 입력값이면 불가능.**

> **재귀함수의 목적 = 개수를 모르는 중첩 반복문 구현**

## 2-2. 템플릿 원칙

> **문제에 맞춰 템플릿을 고치지 말 것.**
> **문제를 템플릿에 맞도록 변형할 것.**

## 2-3. 템플릿 #1 — 중복순열 (M^N)

각 자리에 아무 값이나. 제약 없음.

```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, m;
vector<int> arr;

void rec(int cur)
{
    if (cur == n)                   // 종료
    {
        for (int i = 0; i < n; i++)
        {
            cout << arr[i] << " ";
        }
        cout << "\n";
        return;
    }

    for (int i = 0; i < m; i++)     // 선택지
    {
        arr[cur] = i;
        rec(cur + 1);
    }
}

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    arr.resize(n);
    rec(0);
    return 0;
}
```

**구조**
```
if (종료 조건) { 처리; return; }
for (선택지) { 선택; 재귀; }
```

## 2-4. 템플릿 #2 — 순열 (visited)

한 케이스 안에서 같은 값 중복 불가.

```cpp
int n, m;
vector<int> arr;
vector<bool> visited;

void rec(int cur)
{
    if (cur == n)
    {
        // 출력
        return;
    }

    for (int i = 0; i < m; i++)
    {
        if (visited[i] == true)
        {
            continue;
        }

        visited[i] = true;      // 선택
        arr[cur] = i;
        rec(cur + 1);
        visited[i] = false;     // ★ 복구
    }
}
```

### ★ 최다 실수

```cpp
visited[i] = false;     // 재귀 끝나고 반드시 되돌릴 것
```

**"백트래킹" = 되돌아간다는 뜻.** 복구 코드가 없으면 백트래킹이 아니다. 한 번 쓴 값이 영원히 막힌다.

## 2-5. 템플릿 #3 — 조합 (start)

`012`와 `210`이 같은 것으로 취급될 때.

```cpp
void rec(int cur, int start)
{
    if (cur == n)
    {
        // 출력
        return;
    }

    for (int i = start; i < m; i++)
    {
        arr[cur] = i;
        rec(cur + 1, i);        // 중복 허용
        // rec(cur + 1, i + 1); // 중복 불가
    }
}
```

| 방식 | 다음 시작 | 결과 예시 |
|---|---|---|
| 비내림차순 (중복 허용) | `i` | 000, 001, 011, 111 |
| 오름차순 (중복 불가) | `i + 1` | 012, 013, 023 |

`start` 인자가 **"이전보다 작은 값은 못 고른다"** 는 제약을 걸어 중복 케이스를 원천 차단한다.

## 2-6. 가지치기 (Pruning)

답이 될 수 없는 가지를 미리 자른다. **백트래킹의 진짜 위력.**

```cpp
void rec(int cur, int sum)
{
    if (sum > target)       // ★ 종료 조건보다 먼저
    {
        return;
    }

    if (cur == n)
    {
        // 처리
        return;
    }

    for (int i = 0; i < m; i++)
    {
        arr[cur] = i;
        rec(cur + 1, sum + i);
    }
}
```

## 2-7. 2차원 백트래킹 (스도쿠 등)

**2차원이라고 재귀를 2중으로 만들지 말 것.** 1차원 인덱스로 펴면 템플릿 #1과 같아진다.

```cpp
void rec(int idx)
{
    if (idx == n * m)
    {
        // 완성
        return;
    }

    int x = idx / m;        // 행
    int y = idx % m;        // 열

    for (int val = 1; val <= 9; val++)
    {
        if (isValid(x, y, val) == false)
        {
            continue;
        }

        board[x][y] = val;
        rec(idx + 1);
        board[x][y] = 0;    // 복구
    }
}
```

# PART 3. 시뮬레이션

## 3-1. 정체

> **알고리즘이 아니라 받아쓰기.**
> 문제에 적힌 규칙을 빠짐없이 코드로 옮기는 것.

어려운 이유는 기법이 아니라 **조건이 여러 겹 쌓이기 때문.**

## 3-2. 격자 뼈대 ★ 통째로 외울 것

```cpp
#include <iostream>

using namespace std;

int n, m;
int board[100][100];

// 상 하 좌 우
int dx[4] = {-1, 1, 0, 0};
int dy[4] = {0, 0, -1, 1};

// 8방향이 필요하면
// int dx8[8] = {-1,-1,-1, 0, 0, 1, 1, 1};
// int dy8[8] = {-1, 0, 1,-1, 1,-1, 0, 1};

bool inRange(int x, int y)
{
    return (x >= 0 && x < n && y >= 0 && y < m);
}

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            cin >> board[i][j];
        }
    }

    // 사방 탐색
    int x = 0;
    int y = 0;
    for (int d = 0; d < 4; d++)
    {
        int nx = x + dx[d];
        int ny = y + dy[d];

        if (inRange(nx, ny) == false)
        {
            continue;
        }
        // 처리
    }

    return 0;
}
```

## 3-3. 방향 전환 패턴

### 시계 방향 회전

```cpp
// dx, dy 를 시계 순서로 배열해야 함
// 상(0) → 우(1) → 하(2) → 좌(3)
int dx[4] = {-1, 0, 1, 0};
int dy[4] = {0, 1, 0, -1};

dir = (dir + 1) % 4;        // 시계 90도
```

### 반시계 방향 회전

```cpp
dir = (dir + 3) % 4;        // 반시계 90도
```

**`dir - 1`을 쓰면 음수가 나온다.** C++의 `%`는 음수를 반환하므로 `+3`을 쓸 것.

### 180도 반전

```cpp
dir = (dir + 2) % 4;
```

> **★ 방향 배열의 순서가 회전 문제의 전부.**
> 회전이 있는 문제면 `dx`, `dy`를 **시계 순서로** 배치할 것.

## 3-4. 격자 회전 (90도)

```cpp
// 원본 board(n x m) → 결과 rotated(m x n)
void rotate90(int board[100][100], int rotated[100][100], int n, int m)
{
    for (int i = 0; i < n; i++)
    {
        for (int j = 0; j < m; j++)
        {
            rotated[j][n - 1 - i] = board[i][j];
        }
    }
}
```

**주의: 행과 열 크기가 뒤바뀐다.** n×m → m×n

## 3-5. 원형 배열 처리

두 방법.

```cpp
// 방법 1. 뒤에 이어붙이기 (권장. 실수 적음)
for (int i = 0; i < k - 1; i++)
{
    belt.push_back(belt[i]);
}

// 방법 2. 모듈러 (메모리 절약)
int idx = (i + j) % n;
```

**시험장에서는 방법 1.** 인덱스 계산 실수가 나오지 않는다.

## 3-6. 상태 복사

시뮬레이션은 **동시에 일어나는 변화**를 다루는 경우가 많다.

```cpp
// 틀림. 앞에서 바꾼 값이 뒤 계산에 영향
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < m; j++)
    {
        board[i][j] = calc(i, j);
    }
}

// 맞음. 새 배열에 쓰고 마지막에 교체
int next[100][100];
for (int i = 0; i < n; i++)
{
    for (int j = 0; j < m; j++)
    {
        next[i][j] = calc(i, j);
    }
}
// board = next 로 복사
```

**동시 변화(생명 게임, 확산, 인구 이동)면 무조건 새 배열 사용.**

## 3-7. 시뮬레이션 필승법 — 조건 목록화

> **막히는 이유는 조건을 코딩하면서 발견하기 때문.**
> 먼저 다 꺼내놓으면 막힐 일이 없다.

코드 치기 전 주석으로 조건을 전부 나열한다.

```cpp
// [조건 목록]
// 1. 로봇은 현재 칸을 청소
// 2. 왼쪽 방향부터 차례로 탐색
// 3. 왼쪽에 청소 안 한 공간 있으면 회전 후 전진
// 4. 없으면 방향만 회전
// 5. 네 방향 모두 청소됐으면 후진
// 6. 후진할 수 없으면 종료
```

**조건 하나 = 함수 하나** 로 쪼개면 디버깅이 쉬워진다.

# PART 4. 설계 4칸 (코딩 전 필수)

```cpp
// [상태]     무엇을 들고 다니는가?
// [전이]     다음으로 어떻게 가는가?
// [가지치기] 언제 안 가는가?
// [종료]     언제 끝나고 무엇을 하는가?
```

## 핵심 질문

**[상태]** → **같은 위치에 다른 조건으로 다시 올 수 있는가?**
올 수 있으면 그 조건을 상태에 포함. 방문 배열 차원도 늘어남.

**[가지치기]** → 범위 밖 / 이미 방문 / 조건 초과 / 벽

**[종료]** → 성공 조건과 **실패 조건 둘 다** 적을 것

> **4칸이 안 채워지면 코드 한 줄도 치지 말 것.**
> 안 채워진다 = 문제를 덜 이해했다는 신호.

## 틀렸을 때

**코드를 노려보지 말고 4칸으로 돌아간다.** 대개 조건 하나를 안 적어둔 게 원인이다.

# PART 5. C++ 체크리스트

- [ ] **`visited` 복구** — 백트래킹에서 `false`로 되돌렸는가
- [ ] **음수 방향 인덱스** — `(dir + 3) % 4` 사용. `dir - 1`은 음수
- [ ] **배열 범위** — `inRange()` 먼저 호출. C++는 범위 초과에 에러를 안 냄
- [ ] **전역 배열 크기** — 넉넉히 잡을 것. `board[100][100]`
- [ ] **동시 변화** — 새 배열에 쓰고 교체
- [ ] **경우의 수 계산** — 1억 넘으면 완전탐색 불가
- [ ] **오버플로우** — 누적값이 크면 `long long`
- [ ] **방향 배열 순서** — 회전 문제면 시계 순서로 배치
