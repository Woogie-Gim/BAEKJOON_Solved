# 투포인터 (Two Pointer) — C++

## 0. 핵심

> **포인터 두 개를 움직여 O(N)에 답을 찾는다**

이중 반복문 O(N²)으로 풀 것을 **되돌아가지 않는다**는 성질을 이용해 O(N)으로 줄인다.

---

## 1. 언제 쓰는가

문제에 이런 표현이 보이면 신호.

- **연속 부분 수열**
- 특정 조건을 만족하는 **연속된 구간** 찾기
- 특정 조건을 만족하는 **두 수** 찾기

### 연속 부분 수열 = 투포인터 or 누적합

문제를 읽고 "연속 부분 수열이네" 싶으면 둘 중 하나로 접근.

| 상황 | 기법 |
|---|---|
| 구간 길이가 **고정**이거나 질의로 **주어짐** | 누적합 |
| 구간 길이를 **조건에 맞춰 늘였다 줄여야 함** | 투포인터 |

---

## 2. 유형 1 — 구간 찾기 (같은 방향)

### 아이디어

모든 원소가 **양수**라면

- 끝점 `e`를 오른쪽으로 옮기면 → 합이 **반드시 증가**
- 시작점 `s`를 오른쪽으로 옮기면 → 합이 **반드시 감소**

합이 단조롭게 변하므로 **되돌아갈 필요가 없다.** 이게 O(N)의 근거.

### 동작 규칙

| 현재 상태 | 행동 |
|---|---|
| `total < M` | 합을 키워야 함 → **`e` 전진** |
| `total > M` | 합을 줄여야 함 → **`s` 전진** |
| `total == M` | 카운트 후 **둘 중 아무거나 전진** |

`total == M`에서 아무거나 옮겨도 되는 이유 → 이미 답으로 셌으므로 같은 구간을 다시 볼 필요가 없다.

### 전체 코드 — 예시 1) 백준 2003 수들의 합 2

> N개의 수열에서 연속된 부분합이 정확히 M이 되는 경우의 수
> N ≤ 10,000 / M ≤ 300,000,000 / 각 수는 30,000 이하 자연수

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    vector<int> arr(n);
    for (int i = 0; i < n; i++)
    {
        cin >> arr[i];
    }

    int s = 0;
    int e = 0;
    int total = 0;
    int cnt = 0;

    while (e <= n)
    {
        if (total == m)
        {
            cnt++;
        }

        if (total < m)
        {
            // 합을 키움. 범위 체크 먼저
            if (e == n)
            {
                break;
            }
            total = total + arr[e];
            e++;
        }
        else
        {
            // 합을 줄임
            total = total - arr[s];
            s++;
        }
    }

    cout << cnt << "\n";
    return 0;
}
```

### ★ C++ 주의 — 범위 초과가 조용히 지나간다

`arr[e]`에서 `e`가 `n` 이상이면 **배열 범위를 벗어난다.**

C++는 이때 **에러를 내지 않는다.** 쓰레기 값을 읽고 그대로 진행한다. 로직은 맞는데 답만 틀리는 상황이 나오고, 원인 찾기가 매우 어렵다.

**대응 2가지**

```cpp
// 방법 1. 접근 전 범위 검사 (권장)
if (e == n)
{
    break;
}
total = total + arr[e];

// 방법 2. 배열을 넉넉히 잡아 패딩
vector<int> arr(n + 10, 0);
```

방법 1이 정석. 방법 2는 급할 때 안전장치.

## 3. 유형 2 — 두 수 찾기 (마주보는 방향)

### 아이디어

정렬된 배열에서 양 끝에서 출발해 서로에게 다가간다.

**전제: 정렬 필수.** 원래 순서를 유지할 필요가 없는 문제여야 한다.

### 동작 규칙

| 현재 상태 | 행동 | 이유 |
|---|---|---|
| `arr[s] + arr[e] < X` | **`s` 전진** | 합을 키워야 함 |
| `arr[s] + arr[e] > X` | **`e` 후퇴** | 합을 줄여야 함 |
| `arr[s] + arr[e] == X` | 카운트 후 둘 중 하나 이동 | 이미 셈 |

### 왜 되돌아가지 않아도 되나

정렬된 상태에서 `arr[s] + arr[e] > X` 라면

- `arr[e]`는 **어떤 `s`와 짝지어도 너무 크다**
- 왜? 남은 `s` 후보들은 현재보다 더 큰 값뿐이므로
- 따라서 `e`를 버려도 답을 놓치지 않는다

반대 방향도 동일한 논리.

### 전체 코드 — 예시 2) 백준 3273 두 수의 합

> 서로 다른 n개의 양의 정수에서 두 수의 합이 x가 되는 쌍의 개수
> n ≤ 100,000 / 각 수는 1,000,000 이하 / x ≤ 2,000,000

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    int n;
    cin >> n;

    vector<int> arr(n);
    for (int i = 0; i < n; i++)
    {
        cin >> arr[i];
    }

    int x;
    cin >> x;

    // 순서 유지 불필요 → 정렬부터
    sort(arr.begin(), arr.end());

    int s = 0;
    int e = n - 1;
    int cnt = 0;

    while (s < e)
    {
        int sum = arr[s] + arr[e];

        if (sum == x)
        {
            cnt++;
            s++;            // 둘 중 아무거나
        }
        else if (sum < x)
        {
            s++;            // 크게 만들기
        }
        else
        {
            e--;            // 작게 만들기
        }
    }

    cout << cnt << "\n";
    return 0;
}
```

## 4. 두 유형 비교 ★

| 항목 | 유형 1 (구간 찾기) | 유형 2 (두 수 찾기) |
|---|---|---|
| 출발 | `s = 0`, `e = 0` | `s = 0`, `e = n - 1` |
| 반복 조건 | `e <= n` | `s < e` |
| 이동 방향 | 둘 다 오른쪽으로 | 서로에게 다가감 |
| 정렬 | **하면 안 됨** (연속성 깨짐) | **필수** |
| 용도 | **범위**를 찾을 때 | **수**를 찾을 때 |

> **정렬 여부가 결정적 차이.**
> 연속 부분 수열은 순서가 의미를 가지므로 정렬 금지.
> 두 수 찾기는 순서가 무의미하므로 정렬 필수.

---

## 5. 시간복잡도

| 유형 | 복잡도 |
|---|---|
| 유형 1 | O(N) — `s`, `e` 각각 최대 N번 이동 |
| 유형 2 | O(N log N) — 정렬이 지배 |

이중 반복문 O(N²)과 비교하면

- N = 100,000 → O(N²) = 100억 (불가능)
- N = 100,000 → O(N) = 10만 (즉시)

---

## 6. C++ 체크리스트

- [ ] **배열 범위 초과** — `arr[e]` 접근 전 `e < n` 확인. C++는 에러를 안 냄
- [ ] **오버플로우** — 합이 커지는 문제면 `long long`. N × 최대값 > 21억 기준
- [ ] **정렬 여부** — 유형 1은 금지 / 유형 2는 필수
- [ ] **`while` 종료 조건** — 무한 루프 나면 포인터가 안 움직이는 분기가 있는지 확인

### 무한 루프 방지

모든 분기에서 **포인터가 반드시 하나는 움직여야** 한다.

```cpp
if (sum == x)
{
    cnt++;
    s++;        // ← 이거 빠뜨리면 무한 루프
}
```

## 7. 설계 4칸 (코딩 전 필수)

```
[상태]     s, e, 현재 합(또는 조건값)
[전이]     조건에 따라 s 또는 e 를 어느 방향으로?
[가지치기] 배열 범위 벗어나면? 조건 못 만족하면?
[종료]     while 조건은? 무엇을 반환?
```

## 8. 세 줄 요약

1. **투포인터 = 되돌아가지 않는 성질로 O(N²)을 O(N)으로 줄이는 기법**
2. **유형 1(같은 방향, 정렬 금지)과 유형 2(마주보기, 정렬 필수)를 구분한다**
3. **C++는 배열 범위 초과에 에러를 안 낸다.** 접근 전 범위 검사가 필수

## 9. 관련 개념

- **누적합** — 구간 길이가 고정이거나 질의로 주어질 때
- **이진탐색** — 정렬된 배열에서 값 하나 찾기. 투포인터 유형 2와 사고방식이 유사
- **슬라이딩 윈도우** — 투포인터 유형 1에서 구간 길이가 고정된 특수 형태
