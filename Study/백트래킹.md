# 백트래킹 (Backtracking) — C++

## 0. 왜 배우는가

> **구현을 잘 하기 위해**

완전탐색을 할 줄 알면 절반은 성공. 백트래킹은 **재귀함수를 이용한 완전탐색**이다.

---

## 1. 반복문의 한계

### 자리 수가 고정이면 for문으로 가능

2자리 3진수 모두 출력 → for문 2개

```cpp
for (int i = 0; i < 3; i++)
{
    for (int j = 0; j < 3; j++)
    {
        cout << i << " " << j << "\n";
    }
}
```

### 자리 수가 입력으로 주어지면?

N자리 M진수 → **for문 N개 필요**

N이 입력값이면 for문을 몇 개 쓸지 코드 작성 시점에 알 수 없다. **반복문으로는 불가능.**

> **재귀함수의 목적 = 개수를 알 수 없는 중첩 반복문 구현**

이게 백트래킹을 쓰는 이유의 전부.

---

## 2. 템플릿 사용 원칙

> **문제에 맞춰 템플릿을 고치지 말 것.**
> **문제를 템플릿에 맞도록 변형할 것.**

템플릿을 매번 새로 짜면 실수가 난다. 3종을 손에 익히고 문제를 그 형태로 끌고 온다.

| 템플릿 | 용도 | 특징 |
|---|---|---|
| #1 중복순열 | N자리 M진수 | 아무 제약 없음 |
| #2 순열 | 한 케이스 내 중복 값 없음 | `visited` 배열 |
| #3 조합 | 순서 다르고 값 같으면 같은 것 | `start` 인자 |
| +) 2차원 | 스도쿠 등 격자 | 좌표 → 1차원 변환 |

## 3. 템플릿 #1 — 중복순열 (N자리 M진수)

### 개념

- 각 자리에 0 ~ M-1 아무거나 들어감
- 제약 없음. 가장 단순한 형태
- 출력 개수 = M^N

### 전체 코드 — N자리 M진수 모두 출력

> N과 M을 입력받아 N자리 M진수를 모두 출력
> 예) N=2, M=3 → 00 01 02 10 11 12 20 21 22

```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, m;
vector<int> arr;

void rec(int cur)
{
    // 종료 조건. N자리 다 채움
    if (cur == n)
    {
        for (int i = 0; i < n; i++)
        {
            cout << arr[i] << " ";
        }
        cout << "\n";
        return;
    }

    // cur 자리에 0 ~ m-1 을 하나씩 넣어봄
    for (int i = 0; i < m; i++)
    {
        arr[cur] = i;
        rec(cur + 1);
    }
}

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    arr.resize(n);

    rec(0);
    return 0;
}
```

### 구조 분해

```
if (종료 조건) { 출력; return; }     ← 재귀 탈출
for (선택지) { 선택; 재귀; }          ← 반복문 하나가 자리 하나
```

**for문 하나가 자리 하나**를 담당한다. 재귀 깊이가 곧 자릿수.

## 4. 템플릿 #2 — 순열 (중복 값 제거)

### 개념

- 한 케이스 안에서 **같은 값을 두 번 쓰지 않음**
- `000`, `011` 같은 건 제외
- `visited` 배열로 이미 쓴 값 표시

### 전체 코드 — 순열 출력

> N자리를 만들되 한 케이스 안에서 값이 중복되지 않게
> 예) N=2, M=3 → 01 02 10 12 20 21

```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, m;
vector<int> arr;
vector<bool> visited;

void rec(int cur)
{
    if (cur == n)
    {
        for (int i = 0; i < n; i++)
        {
            cout << arr[i] << " ";
        }
        cout << "\n";
        return;
    }

    for (int i = 0; i < m; i++)
    {
        // 이미 쓴 값이면 건너뜀
        if (visited[i] == true)
        {
            continue;
        }

        visited[i] = true;      // 사용 표시
        arr[cur] = i;
        rec(cur + 1);
        visited[i] = false;     // 원상 복구 ★ 핵심
    }
}

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    arr.resize(n);
    visited.assign(m, false);

    rec(0);
    return 0;
}
```

### ★ 가장 흔한 실수

```cpp
visited[i] = false;   // 재귀 끝난 뒤 반드시 되돌릴 것
```

이 한 줄을 빠뜨리면 **한 번 쓴 값이 영원히 막힌다.** 백트래킹이라는 이름 자체가 "되돌아간다"는 뜻. 되돌리는 코드가 없으면 백트래킹이 아니다.

## 5. 템플릿 #3 — 조합 (같은 케이스 제거)

### 개념

- `012`와 `210`은 **실질적으로 같은 케이스**
- 카드 뽑기처럼 순서가 의미 없을 때
- 중복되는 것 다 지우고 하나만 남김

### 어떻게 하나로 남기나

> **비내림차순으로만 만든다**

비내림차순 = 내림차순이 아닌 것 = **같아도 됨, 커져야 함**

오름차순(엄격히 증가)이 아닌 이유 → `0 0 0` 같이 **같은 값이 반복되는 케이스도 허용**해야 하는 문제가 있기 때문.

| 방식 | 다음 시작 인덱스 | 결과 |
|---|---|---|
| 비내림차순 (중복 허용) | `rec(cur + 1, i)` | 000, 001, 011, 111 |
| 오름차순 (중복 불가) | `rec(cur + 1, i + 1)` | 012, 013, 023 |

문제 조건에 따라 `i` / `i + 1` 중 선택.

### 전체 코드 — 조합 출력

> 순서가 다르지만 값의 구성이 같으면 같은 것으로 취급
> 비내림차순으로만 생성해서 중복 제거

```cpp
#include <iostream>
#include <vector>

using namespace std;

int n, m;
vector<int> arr;

// start 이상의 값만 사용 → 비내림차순 보장
void rec(int cur, int start)
{
    if (cur == n)
    {
        for (int i = 0; i < n; i++)
        {
            cout << arr[i] << " ";
        }
        cout << "\n";
        return;
    }

    for (int i = start; i < m; i++)
    {
        arr[cur] = i;
        rec(cur + 1, i);        // 중복 허용. 불가면 i + 1
    }
}

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    cin >> n >> m;
    arr.resize(n);

    rec(0, 0);
    return 0;
}
```

### 원리

`start` 인자가 **"이전에 고른 값보다 작은 건 못 고른다"** 는 제약을 건다. 그래서 `210` 같은 순서는 애초에 생성되지 않는다.

## 6. +) 2차원 백트래킹 (스도쿠 등)

격자를 채우는 문제. 좌표 두 개를 재귀 인자로 넘기면 복잡해진다.

> **1차원 인덱스로 변환해서 템플릿 #1을 그대로 쓴다**

```cpp
// (행, 열) → 1차원 인덱스
// idx = 행 * 열개수 + 열
// 역변환: 행 = idx / 열개수, 열 = idx % 열개수

void rec(int idx)
{
    if (idx == n * m)       // 전부 채움
    {
        // 출력
        return;
    }

    int x = idx / m;
    int y = idx % m;

    for (int val = 1; val <= 9; val++)
    {
        if (isValid(x, y, val) == false)
        {
            continue;
        }

        board[x][y] = val;
        rec(idx + 1);
        board[x][y] = 0;    // 복구
    }
}
```

**핵심: 2차원이라고 재귀를 2중으로 만들지 말 것.** 인덱스 하나로 펴면 템플릿 #1과 완전히 같아진다.

## 7. C++ 전용 — `next_permutation`

순열이 필요한 문제라면 재귀 없이 처리 가능.

```cpp
#include <iostream>
#include <vector>
#include <algorithm>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    vector<int> v;
    v.push_back(1);
    v.push_back(2);
    v.push_back(3);

    // 반드시 정렬된 상태에서 시작
    sort(v.begin(), v.end());

    do
    {
        for (int i = 0; i < (int)v.size(); i++)
        {
            cout << v[i] << " ";
        }
        cout << "\n";
    } while (next_permutation(v.begin(), v.end()));

    return 0;
}
```

| 항목 | 주의 |
|---|---|
| 정렬 | **반드시 오름차순 정렬 후 시작.** 안 하면 일부 순열이 누락됨 |
| 반복문 | `while`이 아니라 `do-while`. 첫 순열도 출력해야 하므로 |
| 반환값 | 다음 순열이 없으면 `false` |
| 조합 | `next_permutation`은 순열 전용. 조합은 0/1 배열 트릭 필요 |

**언제 쓰나** → 순열 전체를 순회하며 각각 평가하는 문제. 재귀보다 짧고 실수가 적다.

**언제 재귀를 쓰나** → 중간에 가지치기가 필요할 때. `next_permutation`은 전부 생성하므로 가지치기 불가.

## 8. 시간복잡도

| 템플릿 | 경우의 수 |
|---|---|
| #1 중복순열 | M^N |
| #2 순열 | M × (M-1) × ... = M! / (M-N)! |
| #3 조합 | C(M, N) |

**완전탐색은 지수 시간.** N, M이 조금만 커져도 터진다.

> **판단 기준: 경우의 수가 1,000만 이하인지 계산해볼 것**

- M=10, N=7 → 10^7 = 1,000만 → 아슬아슬
- M=10, N=8 → 1억 → 시간 초과

문제의 제한 조건이 작으면(보통 N ≤ 10~20) 백트래킹 신호.

## 9. 가지치기 (Pruning)

완전탐색을 그냥 돌리면 느리다. **답이 될 수 없는 가지를 미리 잘라내는** 것이 백트래킹의 진짜 위력.

```cpp
void rec(int cur, int sum)
{
    // 가지치기. 이미 답을 넘었으면 더 볼 필요 없음
    if (sum > target)
    {
        return;
    }

    if (cur == n)
    {
        // 처리
        return;
    }

    for (int i = 0; i < m; i++)
    {
        arr[cur] = i;
        rec(cur + 1, sum + i);
    }
}
```

가지치기 조건은 **종료 조건보다 먼저** 검사한다.

## 10. 설계 4칸 (코딩 전 필수)

```
[상태]     재귀 함수가 들고 다니는 것은? (cur, start, sum ...)
[전이]     다음 단계로 어떻게 가는가? (arr[cur] = i; rec(cur+1))
[가지치기] 언제 안 가는가? (visited / start / 조건 초과)
[종료]     언제 끝나고 무엇을 하는가? (cur == n → 출력)
```

**4칸이 안 채워지면 코딩 시작 금지.** 백트래킹은 특히 중간에 막히면 복구가 어렵다.

## 11. 세 줄 요약

1. **백트래킹 = 개수를 모르는 중첩 반복문을 재귀로 구현하는 것**
2. **템플릿 3개를 외우고 문제를 템플릿에 맞게 변형한다** (반대 아님)
3. **`visited[i] = false` 복구를 빠뜨리지 말 것.** 되돌리지 않으면 백트래킹이 아니다
