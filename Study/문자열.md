# PART 1. sstream

## 1-1. 정체

> **문자열을 `cin`처럼 읽게 해주는 도구**

`cin`은 키보드에서 읽고 `stringstream`은 문자열에서 읽는다. 동작은 완전히 같다. 공백을 알아서 건너뛰고 음수 부호도 처리하고 여러 자리 수도 통째로 읽는다.

```cpp
#include <sstream>

stringstream ss("10 -20 30");

int x;
ss >> x;    // 10
ss >> x;    // -20
ss >> x;    // 30
```

## 1-2. 형태 ① 공백 구분 정수 ★ 최빈출

```cpp
#include <string>
#include <vector>
#include <sstream>

using namespace std;

stringstream ss(s);
vector<int> v;

int x;
while (ss >> x)             // 더 읽을 게 없으면 false
{
    v.push_back(x);
}
```

`"10 -20 30 400"` → `{10, -20, 30, 400}`

**`while (ss >> x)` 가 핵심.** 읽기 성공하면 참, 실패하면 거짓.

## 1-3. 형태 ② 공백 구분 단어

```cpp
stringstream ss(s);
vector<string> words;

string word;
while (ss >> word)
{
    words.push_back(word);
}
```

`"  hello   world  foo "` → `{"hello", "world", "foo"}`

> **앞뒤 공백과 연속 공백을 알아서 무시한다.** 단어 개수 세기 문제에 그대로 쓰면 된다.

## 1-4. 형태 ③ 구분자 지정

```cpp
stringstream ss("1,22,333");
string token;

while (getline(ss, token, ','))     // 세 번째 인자가 구분자
{
    v.push_back(stoi(token));
}
```

쉼표·콜론·하이픈 등으로 나눌 때. `getline`에 구분자를 넘긴다.

## 1-5. 역방향 — 조립

```cpp
stringstream ss;
ss << 10 << " " << -20;

string result = ss.str();   // "10 -20"
```

`to_string`으로도 되니 굳이 안 써도 무방.

## 1-6. 언제 쓰나 — 판단 기준 ★

| 상황 | 도구 |
|---|---|
| 한 글자가 한 숫자 (`"12345"`) | `s[i] - '0'` |
| 공백으로 구분 (`"10 -20 30"`) | **`stringstream`** |
| 다른 문자로 구분 (`"1,2,3"`) | `getline(ss, token, ',')` |

> **여러 자리 수나 음수가 섞이면 반드시 `stringstream`.**
> 한 글자씩 읽으면 `-1`이 `'-'`와 `'1'`로 쪼개지고 `10`이 `1`과 `0`으로 망가진다.

## 1-7. 주의

**1. `#include <sstream>` 필수**

**2. 한 번 읽으면 되감기 안 됨**

```cpp
while (ss >> x) { ... }
while (ss >> x) { ... }     // 두 번째는 아무것도 안 읽힘
```

다시 읽으려면

```cpp
ss.clear();
ss.str(s);
```

코테에서 두 번 읽을 일은 거의 없음.

# PART 2. string 필수 함수

```cpp
#include <string>

string s = "hello world";
```

| 함수 | 동작 | 결과 |
|---|---|---|
| `s.size()` / `s.length()` | 길이 | 11 |
| `s[i]` | i번째 문자 | `s[0]` → `'h'` |
| `s.substr(i, len)` | i부터 len개 | `s.substr(0,5)` → `"hello"` |
| `s.substr(i)` | i부터 끝까지 | `s.substr(6)` → `"world"` |
| `s.find("ab")` | 위치. 없으면 `string::npos` | `s.find("world")` → 6 |
| `s += "ab"` | 뒤에 붙이기 | |
| `s.push_back('a')` | 문자 하나 붙이기 | |
| `s.erase(i, len)` | 삭제 | |
| `s.insert(i, "ab")` | 삽입 | |
| `s.replace(i, len, "ab")` | 치환 | |
| `s.empty()` | 비었는가 | |

## 2-1. find 결과 확인 ★

```cpp
if (s.find("world") != string::npos)
{
    // 찾음
}
```

**`npos`는 "못 찾음"을 뜻하는 특수값.** `-1`이 아니라 엄청 큰 수라 `< 0` 비교로는 못 잡는다.

## 2-2. 문자열도 정렬된다

```cpp
#include <algorithm>

string t = "52413";
sort(t.begin(), t.end());                   // "12345"
sort(t.begin(), t.end(), greater<char>());  // "54321"
reverse(t.begin(), t.end());
```

> **문자 `'0'`~`'9'`의 아스키 코드가 48~57로 연속이라 문자 정렬 = 숫자 정렬.**
> 숫자를 자리별로 정렬할 때 `vector<int>`로 옮길 필요 없음.

# PART 3. 문자 ↔ 숫자 변환

## 3-1. 변환표 ★ 외울 것

| 방향 | 코드 | 예 |
|---|---|---|
| 문자 → 숫자 | `c - '0'` | `'7' - '0'` → 7 |
| 숫자 → 문자 | `(char)(n + '0')` | `5` → `'5'` |
| 문자열 → int | `stoi(s)` | |
| 문자열 → long long | **`stoll(s)`** | |
| 정수 → 문자열 | `to_string(n)` | |

## 3-2. ★ `(int)` 캐스팅은 변환이 아니다

```cpp
int n = (int)'7';       // 55 (아스키 코드)
int n = '7' - '0';      // 7  (진짜 숫자)
```

**`(int)`는 아스키 코드를 꺼낼 뿐이다.** 가장 흔한 실수.

## 3-3. 대소문자

```cpp
char up = 'a' - 32;         // 'A'  아스키 차이 32
char low = 'A' + 32;        // 'a'

#include <cctype>
char up = toupper('a');     // 'A'  이쪽이 안전
char low = tolower('A');    // 'a'
```

## 3-4. 문자 판별

```cpp
#include <cctype>

isdigit(c)      // 숫자인가
isalpha(c)      // 알파벳인가
isupper(c)      // 대문자인가
islower(c)      // 소문자인가
isspace(c)      // 공백인가
```

# PART 4. ★ 자료형 함정 (기출 반복 확인)

문자열 문제에 자료형 함정이 섞여 나오는 패턴이 여러 회차에서 확인됨.

## 4-1. 체크리스트

- [ ] **입력 최대 크기** → 자리 수를 세어볼 것
- [ ] **`stoi` vs `stoll`** → 10자리 넘으면 `stoll`
- [ ] **어떤 자료형에도 안 들어가면** → 문자열 그대로 자리별 계산
- [ ] **실수 나눗셈** → 나누기 **전에** `(double)` 캐스팅

## 4-2. stoi 한계

| 함수 | 범위 | 자리 수 |
|---|---|---|
| `stoi` | 약 21억 | 10자리 |
| `stoll` | 약 922경 | 19자리 |

**둘 다 넘으면 변환 자체가 불가능.** 문자열 상태로 처리해야 한다.

## 4-3. 큰 수 덧셈 (자료형 초과 시)

세로셈을 그대로 구현한다.

```cpp
#include <string>
#include <algorithm>

using namespace std;

string bigAdd(string a, string b)
{
    // 일의 자리부터 접근하려고 뒤집음
    reverse(a.begin(), a.end());
    reverse(b.begin(), b.end());

    string answer = "";
    int carry = 0;
    int len = max((int)a.size(), (int)b.size());

    for (int i = 0; i < len; i++)
    {
        int sum = carry;

        if (i < (int)a.size())
        {
            sum = sum + (a[i] - '0');
        }
        if (i < (int)b.size())
        {
            sum = sum + (b[i] - '0');
        }

        answer += (char)(sum % 10 + '0');   // 현재 자리
        carry = sum / 10;                    // 올림
    }

    if (carry > 0)
    {
        answer += (char)(carry + '0');
    }

    reverse(answer.begin(), answer.end());
    return answer;
}
```

**핵심 3줄**
- `a[i] - '0'` — 문자를 숫자로
- `sum % 10` — 현재 자리에 남길 값
- `sum / 10` — 다음 자리로 넘길 올림

# PART 5. 자주 쓰는 패턴

## 5-1. 각 문자 카운팅

```cpp
int count[26] = {0};        // 알파벳 소문자

for (int i = 0; i < (int)s.size(); i++)
{
    count[s[i] - 'a']++;    // 문자를 인덱스로
}
```

**값을 인덱스로 쓰는 버킷 방식.** `'a'`를 빼면 0~25 범위가 된다.

대소문자 모두 필요하면 `count[52]` 또는 `count[128]`(아스키 전체).

## 5-2. 자릿수 합

```cpp
int sum = 0;
string s = to_string(n);

for (int i = 0; i < (int)s.size(); i++)
{
    sum = sum + (s[i] - '0');
}
```

`/`, `%` 로도 가능.

```cpp
int sum = 0;
while (n > 0)
{
    sum = sum + n % 10;
    n = n / 10;
}
```

## 5-3. 문자열 뒤집기

```cpp
reverse(s.begin(), s.end());
```

## 5-4. 부분 문자열 치환 (전부)

```cpp
int pos = 0;
while ((pos = (int)s.find("ab", pos)) != (int)string::npos)
{
    s.replace(pos, 2, "X");
    pos = pos + 1;
}
```

## 5-5. 공백 기준 단어 개수

```cpp
stringstream ss(s);
string word;
int cnt = 0;

while (ss >> word)
{
    cnt++;
}
```

**연속 공백과 앞뒤 공백을 알아서 처리한다.** 직접 세면 경계 조건에서 틀리기 쉬움.

# PART 6. 예제 문제 — 접근법

> 지금은 풀지 말고 **접근법만 읽고 넘길 것.**
> 시뮬레이션 구간(Day 9)에서 실제로 풀 것.

## 6-1. 기초

| 문제 | 출처 | 접근 |
|---|---|---|
| 문자열 다루기 기본 | 프로그래머스 Lv.1 | 길이 검사 + `isdigit` 전수 확인 |
| 문자열 내 p와 y의 개수 | 프로그래머스 Lv.1 | 대소문자 통일 후 카운팅 |
| 자릿수 더하기 | 프로그래머스 Lv.1 | `%`, `/` 또는 문자열 순회 |
| 서울에서 김서방 찾기 | 프로그래머스 Lv.1 | 인덱스 찾기 + `to_string` |

## 6-2. 카운팅 · 변환

| 문제 | 출처 | 접근 |
|---|---|---|
| 문자열 내림차순으로 배치하기 | 프로그래머스 Lv.1 | `sort` + `greater<char>()` |
| 이상한 문자 만들기 | 프로그래머스 Lv.1 | 단어별 인덱스 추적. **공백 처리가 함정** |
| 시저 암호 | 프로그래머스 Lv.1 | 알파벳 순환. `% 26` + 공백 예외 |
| 3진법 뒤집기 | 프로그래머스 Lv.1 | 진법 변환 + 뒤집기 |

**이상한 문자 만들기 주의** — 공백을 만나면 인덱스가 리셋된다. 전체 인덱스가 아니라 **단어 내 인덱스**를 세야 함.

**시저 암호 주의** — `'z'` 다음이 `'a'`가 되도록 `% 26`. 대소문자 따로 처리하고 공백은 그대로 둘 것.

## 6-3. 조건 겹침 ★ 실제 출제 형태

| 문제 | 출처 | 겹친 조건 |
|---|---|---|
| 숫자 문자열과 영단어 | 프로그래머스 Lv.1 | 영단어 → 숫자 치환 + 조합 |
| 신규 아이디 추천 | 프로그래머스 Lv.1 | **7단계 규칙 순차 적용** |
| JadenCase 문자열 만들기 | 프로그래머스 Lv.2 | 단어 첫 글자 대문자 + 숫자 뒤 처리 |
| 오픈채팅방 | 프로그래머스 Lv.2 | `map` + 최종 상태 반영 |
| 튜플 | 프로그래머스 Lv.2 | 파싱 + 길이순 정렬 |

**신규 아이디 추천이 이 유형의 교과서.** 규칙이 7단계로 주어지고 순서대로 적용해야 한다. 조건 목록화 훈련에 최적.

**오픈채팅방 주의** — 닉네임이 중간에 바뀌면 이전 기록도 소급 반영된다. 기록을 저장해두고 **마지막에 한 번에** 출력할 것.

# PART 7. C++ 체크리스트

- [ ] **`(int)` 캐스팅 ≠ 변환** → `- '0'` 사용
- [ ] **`stoi` vs `stoll`** → 10자리 넘으면 `stoll`
- [ ] **`find` 실패 판정** → `!= string::npos`
- [ ] **`" "` vs `' '`** → 문자열 붙일 땐 큰따옴표
- [ ] **`char + char`는 숫자 덧셈** → `to_string`으로 감쌀 것
- [ ] **`size()`는 부호 없는 정수** → `(int)` 캐스팅
- [ ] **여러 자리 수·음수 파싱** → `stringstream`

## ★ 문자열 붙이기 함정

```cpp
// 틀림. 아스키 코드끼리 덧셈
answer = (char)v[0] + ' ' + (char)v[1];

// 맞음. string이 하나라도 있어야 문자열 연결
answer = to_string(v[0]) + " " + to_string(v[1]);
```
