# 누적합 (Prefix Sum) — C++

## 0. 핵심

> **미리 다 더해놓고 필요할 때 빼서 쓴다**

구간 합을 매번 더하지 않는다. 전체를 한 번 더해둔 배열에서 **필요 없는 앞부분을 빼내는** 방식.

---

## 1. 왜 쓰는가 — 시간복잡도

### 상황
길이 N 배열에서 구간 [a, b]의 합을 M번 질의.

### 방법 1) 매번 더하기

```cpp
// 질의마다 구간을 직접 순회
for (int q = 0; q < m; q++)
{
    int a, b;
    cin >> a >> b;

    int sum = 0;
    for (int i = a; i <= b; i++)   // 최악 N번
    {
        sum = sum + arr[i];
    }
    cout << sum << "\n";
}
```

질의 1회당 최악 O(N) → 총 **O(N × M)**

N = 100,000 / M = 100,000 이면 **100억 번**. 1초 제한에서 불가능. 통상 1초에 1억 번이 한계.

### 방법 2) 누적합

| 단계 | 시간복잡도 |
|---|---|
| 누적합 배열 만들기 | O(N) — 딱 한 번 |
| 질의 1회 | **O(1)** |
| 전체 | **O(N + M)** |

100,000 + 100,000 = 20만 번. 100억 → 20만으로 **5만 배** 감소.

**아이디어: 전처리에 O(N) 투자해서 질의를 O(1)로 만든다.** 질의가 많을수록 이득이 커진다.

## 2. 1차원 누적합

### 정의

```
prefix[i] = arr[1] + arr[2] + ... + arr[i]
```

**처음부터 i번째까지의 합**

### 점화식

```
prefix[i] = prefix[i - 1] + arr[i]
```

바로 앞까지의 합에 현재 값만 더한다. 한 번의 순회로 완성.

### 구간합 공식 — 빼내기

구간 [a, b]의 합:

```
answer = prefix[b] - prefix[a - 1]
```

**유도 과정**

```
prefix[b]     = arr[1] + arr[2] + ... + arr[a-1] + arr[a] + ... + arr[b]
prefix[a-1]   = arr[1] + arr[2] + ... + arr[a-1]
                └──────── 빼낼 부분 ────────┘

빼면        =                                 arr[a] + ... + arr[b]
```

**"1번부터 b까지 다 더한 것"에서 "1번부터 a-1까지"를 빼면 "a부터 b까지"만 남는다.** 누적합의 전부.

### 1-indexing 쓰는 이유

배열 맨 앞 0번 칸을 비워두고 1번부터 사용.

`a = 1`일 때 `prefix[a - 1]`이 `prefix[0]`이 된다. 0-indexing이면 `prefix[-1]`로 터짐. 앞에 0을 깔아두면 **경계 예외 처리 없이** 공식이 그대로 동작.

```cpp
vector<int> arr(n + 1, 0);      // 크기 n+1. 0번은 안 씀
vector<int> prefix(n + 1, 0);   // prefix[0] = 0 이 안전장치
```

`prefix[0] = 0`인 이유 → "아무것도 안 더한 상태 = 0". 의미상으로도 맞음.

### 전체 코드 — 예시 1) 백준 11659 구간 합 구하기 4

> 수 N개에서 i번째부터 j번째까지의 합을 M번 질의
> N, M ≤ 100,000 / 각 수는 1,000 이하 자연수

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    // 1번 인덱스부터 사용. 0번은 비워둠
    vector<int> arr(n + 1, 0);
    vector<int> prefix(n + 1, 0);

    for (int i = 1; i <= n; i++)
    {
        cin >> arr[i];
    }

    // 전처리 O(N)
    for (int i = 1; i <= n; i++)
    {
        prefix[i] = prefix[i - 1] + arr[i];
    }

    // 질의 처리. 각 O(1)
    for (int q = 0; q < m; q++)
    {
        int a, b;
        cin >> a >> b;
        cout << prefix[b] - prefix[a - 1] << "\n";
    }

    return 0;
}
```

### 축약형

arr를 따로 두지 않고 prefix에 바로 누적.

```cpp
vector<int> prefix(n + 1, 0);

for (int i = 1; i <= n; i++)
{
    int x;
    cin >> x;
    prefix[i] = prefix[i - 1] + x;   // 입력받으면서 바로 누적
}
```

메모리 절반 + 코드 짧음. 원본 배열이 나중에 필요 없으면 이쪽.

## 3. 고정 길이 구간의 최댓값

길이가 K로 **고정된** 구간 중 합이 최대인 것 찾기.

```
구간 [i-K+1, i] 의 합 = prefix[i] - prefix[i - K]
```

여기도 동일. **전체에서 앞부분을 빼내는** 것뿐.

### 전체 코드 — 예시 2) 백준 2559 수열

> N일간 온도에서 연속 K일 합의 최댓값
> N ≤ 100,000 / 온도는 -100 ~ 100 (음수 포함)

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    int n, k;
    cin >> n >> k;

    vector<int> prefix(n + 1, 0);

    for (int i = 1; i <= n; i++)
    {
        int x;
        cin >> x;
        prefix[i] = prefix[i - 1] + x;
    }

    // 첫 구간으로 초기화. 0으로 두면 음수 답에서 틀림
    int ans = prefix[k] - prefix[0];

    for (int i = k + 1; i <= n; i++)
    {
        int cur = prefix[i] - prefix[i - k];
        if (cur > ans)
        {
            ans = cur;
        }
    }

    cout << ans << "\n";
    return 0;
}
```

### 주의 — 초기값 0으로 두면 안 되는 경우

`ans = 0`으로 시작하면 **값에 음수가 섞일 때 틀린다.** 모든 구간 합이 음수인 입력에서 답이 음수여야 하는데 0을 출력.

> 예: `5 2 / -5 -3 -8 -2 -9` → 정답 -8 인데 0 출력

원소가 전부 양수로 보장되면 `ans = 0`도 무방. 하지만 습관적으로 **첫 구간 값으로 초기화**하거나 `INT_MIN` 사용할 것. 최댓값·최솟값 문제 단골 실수.

## 4. 2차원 누적합

### 정의

```
prefix[i][j] = (1,1)부터 (i,j)까지 직사각형 안의 모든 값의 합
```

**왼쪽 위 모서리부터 (i, j)까지의 직사각형 합**

### 만들기 — 포함배제

```cpp
prefix[i][j] = prefix[i - 1][j]      // 위쪽 직사각형
             + prefix[i][j - 1]      // 왼쪽 직사각형
             - prefix[i - 1][j - 1]  // 두 번 더해진 겹침 제거
             + arr[i][j];            // 현재 칸
```

**왜 빼는가** → 위쪽 직사각형과 왼쪽 직사각형은 좌상단 영역을 **공유**한다. 그냥 더하면 그 부분이 두 번 들어감. 겹친 만큼 한 번 뺀다.

```
    위쪽(prefix[i-1][j])        왼쪽(prefix[i][j-1])
    ┌─────────┐                 ┌──────┐
    │AAAAAAAAA│                 │AAAAAA│
    │AAAAAAAAA│                 │AAAAAA│
    └─────────┘                 │      │
                                └──────┘
        겹치는 부분 = prefix[i-1][j-1]  ← 한 번 빼야 함
```

### 구간합 질의

(x1, y1) ~ (x2, y2) 직사각형의 합:

```cpp
sum = prefix[x2][y2]
    - prefix[x1 - 1][y2]        // 위쪽 잘라내기
    - prefix[x2][y1 - 1]        // 왼쪽 잘라내기
    + prefix[x1 - 1][y1 - 1];   // 두 번 뺀 부분 복구
```

**흐름**

```
1) prefix[x2][y2]        전체를 통째로 가져옴
   ┌──────────────┐
   │██████████████│
   │██████████████│
   │██████████████│
   └──────────────┘

2) - prefix[x1-1][y2]    위쪽 띠 제거
   ┌──────────────┐
   │░░░░░░░░░░░░░░│  ← 제거
   │██████████████│
   │██████████████│
   └──────────────┘

3) - prefix[x2][y1-1]    왼쪽 띠 제거
   ┌────┬─────────┐
   │░░░░│░░░░░░░░░│
   │░░░░│█████████│
   │░░░░│█████████│
   └────┴─────────┘
        ↑ 좌상단 모서리가 2번 3번에서 두 번 빠짐

4) + prefix[x1-1][y1-1]  두 번 빠진 모서리 복구
```

1차원에서 앞부분 하나만 빼면 됐던 것이 2차원에선 **위·왼쪽을 빼고 중복으로 뺀 모서리를 되돌리는** 형태로 확장. 원리는 동일.

### 전체 코드 — 예시 3) 백준 11660 구간 합 구하기 5

> N×N 표에서 (x1,y1)~(x2,y2) 직사각형 영역의 합을 M번 질의
> N ≤ 1,024 / M ≤ 100,000

```cpp
#include <iostream>
#include <vector>

using namespace std;

int main()
{
    ios_base::sync_with_stdio(0);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    // (n+1) x (n+1). 0행 0열은 비워둠
    vector<vector<int>> arr(n + 1, vector<int>(n + 1, 0));
    vector<vector<int>> prefix(n + 1, vector<int>(n + 1, 0));

    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            cin >> arr[i][j];
        }
    }

    // 전처리 O(N^2)
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            prefix[i][j] = prefix[i - 1][j]
                         + prefix[i][j - 1]
                         - prefix[i - 1][j - 1]
                         + arr[i][j];
        }
    }

    // 질의 처리. 각 O(1)
    for (int q = 0; q < m; q++)
    {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;

        int sum = prefix[x2][y2]
                - prefix[x1 - 1][y2]
                - prefix[x2][y1 - 1]
                + prefix[x1 - 1][y1 - 1];

        cout << sum << "\n";
    }

    return 0;
}
```

시간복잡도 → 전처리 O(N²) + 질의 O(1) × M = **O(N² + M)**

## 5. C++에서만 신경 쓸 것

### 5-1. 오버플로우 ★ 가장 흔한 함정

**`int`의 한계는 약 21억(2,147,483,647)**. 누적합은 계속 더해나가는 구조라 값이 금방 커진다. 원소 하나하나는 작아도 N개를 다 더하면 범위를 넘긴다.

| 상황 | 최대 누적합 | 자료형 |
|---|---|---|
| N = 100,000 / 값 ≤ 1,000 | 약 1억 | `int` 가능 |
| N = 100,000 / 값 ≤ 1,000,000 | 약 1,000억 | **`long long` 필수** |

> **판단 기준: N × (값의 최대치) > 21억 이면 `long long`**

```cpp
vector<long long> prefix(n + 1, 0);
```

애매하면 그냥 `long long`. 메모리 여유 있는 문제가 대부분이고 오버플로우는 디버깅이 어렵다. 출력은 그대로 `cout <<` 하면 됨.

### 5-2. 입출력 속도

N / M이 각각 10만이면 입출력만 20만 줄. 최적화 빼먹으면 **로직이 맞아도 시간 초과**.

```cpp
ios_base::sync_with_stdio(0);
cin.tie(0);
```

출력에 `endl` 대신 `"\n"` 쓰는 것도 같은 이유.

### 5-3. 메모리

2차원에서 N = 1,000 이면 `int` 배열 하나가 1,000 × 1,000 × 4바이트 ≈ 4MB. `arr` + `prefix` 둘 다면 8MB. `long long`이면 16MB.

메모리 제한이 빡빡하면 **arr 없이 prefix에 바로 입력받아 누적**해서 절반 절약.

### 5-4. 배열 선언 정리

자주 쓰는 형태만 모아둠.

```cpp
vector<int> v(n + 1, 0);                            // 1차원. 0으로 초기화
vector<long long> v(n + 1, 0);                      // 오버플로우 대비
vector<vector<int>> v(n + 1, vector<int>(m + 1, 0)); // 2차원
```

전역 배열로 잡으면 자동 0 초기화 + 크기 여유가 있다.

```cpp
int prefix[100001];        // 전역. 자동으로 0
long long prefix2[1001][1001];
```

## 6. 세 줄 요약

1. **누적합 = 다 더해놓고 필요 없는 앞부분을 빼는 기법.** 전처리 O(N) / 질의 O(1)
2. **1-indexing으로 앞에 0을 깔면** `prefix[a-1]` 경계 예외가 사라진다
3. **2차원은 포함배제.** 위·왼쪽 빼고 두 번 뺀 모서리를 되돌린다

---

## 7. 적용 대상

- 구간 합을 **여러 번** 질의하는 문제 (질의 1~2번이면 그냥 더하는 게 낫다)
- 고정 길이 구간의 최대·최소
- 2차원 격자에서 직사각형 영역 합
- 조건을 만족하는 구간 개수 세기 (누적합 + `map` 조합)

### 투포인터와 구분

| 상황 | 기법 |
|---|---|
| 구간 길이가 **고정**이거나 질의로 **주어짐** | 누적합 |
| 구간 길이를 **조건에 맞춰 늘였다 줄여야 함** | 투포인터 |
